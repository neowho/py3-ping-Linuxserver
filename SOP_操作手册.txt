SaoMiao_Ping 操作方法 SOP 手册
版本 2.0.0
适用程序：SaoMiao_Ping.exe
所在目录：SaoMiao_Ping

一、这个程序
1. SaoMiao_Ping.py、SaoMiao_Ping.exe 是单独的并发 Ping 程序。
2. 它用 icmplib 直接发 ICMP 包，每台 4 个包，同时最多 80 台。
3. 不调用 ping.exe，也不调用 nmap.exe。不要和 SaoMiao_Nmap 放在同一个窗口里使用。
4. IP_LieBiao.txt 放在 exe 旁边。一行一个 IPv4，井号后面是注释。
5. 点“日志报告”后，报告保存在 exe 旁边的 reports 目录，编码是 UTF-8。

二、使用前
1. 只检测你本人有权检测的服务器。
2. 双击 SaoMiao_Ping.exe。不需要另外安装 Python。
3. exe 用 Python 3.12 打包，适合 Windows 10 和 Windows 11 的 64 位系统。
4. 如果双击后没有窗口，先安装 Microsoft Visual C++ 2015–2022 运行库（x64）：https://aka.ms/vs/17/release/vc_redist.x64.exe
5. 如果日志写明 ICMP 套接字没有权限，用管理员身份重新打开。

三、单个或多个 IP，以及多行地址
1. 在第一行填写一个 IPv4，例如 192.168.1.10。多个地址用英文逗号分开，例如 192.168.1.10,192.168.1.11,192.168.1.12。
2. 点“测试 Ping”，或在输入框按回车。右侧每个地址一行：绿灯写“Ping通”，红灯写“未Ping通”。
3. 多个地址直接粘贴到左侧“多行地址”大框，每行一个 IP，然后点“Ping 框内地址”。
4. 也可以点“加入列表”，再从“多IP服务器”菜单测试。
5. 每台发送 4 个 ICMP 包，每个包最多等待 1 秒。
6. 日志出现“可以 Ping 通（收到 N 次回复，发送 4 个……）”或“无法 Ping 通”。

四、多 IP 服务器下拉菜单
1. 在“单个 IP”或“多行地址”里填写地址，点“添加”或“加入列表”。
2. 或点“导入 IP_LieBiao.txt”。
3. 地址出现在“多 IP 服务器列表”后，点黑色按钮“多IP服务器”。
4. 下拉菜单里可以选择：
   - Ping 全部已加入的服务器
   - Ping 列表里选中的服务器
   - Ping 某一个已列出的地址
5. 点中一项后立即开始。每台仍然发送 4 个包，多台同时进行。
6. 菜单最多列出前 500 个地址。点“Ping 全部已加入的服务器”会测试完整列表，上限 5000 个。
7. “删除选中”和“清空列表”只改列表，不会去 Ping。

五、IP 连续网段下拉菜单
1. 在“起始IP”填写这一段的第一个地址。
2. 如果要自定义起止，再在“结束IP”填写最后一个地址。起始地址要小于或等于结束地址。
3. 点黑色按钮“IP连续网段”。
4. 下拉菜单里可以选择：
   - 按起始IP到结束IP连续 Ping
   - 同网段最后一段 1 到 50
   - 同网段最后一段 51 到 100
   - 同网段最后一段 101 到 150
   - 同网段最后一段 151 到 200
   - 同网段最后一段 201 到 254
   - 同网段最后一段 1 到 254
5. “同网段”只取起始 IP 的前三段。例如起始 IP 是 192.168.1.10，选择“1 到 50”时，测试 192.168.1.1 到 192.168.1.50。
6. 一次最多 512 个地址。超过时程序会提示，不会开始。
7. 网段里的每台也发送 4 个包，多台同时进行。点“停止”后，还没开始的地址不再探测；已经发出的这一轮会等到本次超时。

六、日志报告
1. 右上角有“日志报告”“打开报告目录”“清空日志”。
2. 点“日志报告”后，文件保存到 exe 旁边的 reports 目录。
3. 提示是否打开时，点“是”会用系统默认程序打开。

七、结果判断
1. “可以 Ping 通（收到 N 次回复，发送 4 个，平均 … ms）”表示收到了回复。
2. “无法 Ping 通”表示这次没有收到回复。服务器禁止 Ping 时也会出现这一句，不代表端口一定关闭。
